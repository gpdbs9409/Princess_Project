# 사이드프로젝트 기록 1. 토큰 단가가 더 싼 모델이 7배 비쌌던 이야기

요즘 사이드프로젝트를 하나 하고 있습니다. '프린세스 다이어리'라고, 30일동안 매일 미션을 인증하면서 스스로를 성장시키는 챌린지 서비스인데요. 소설 빙의물 세계관을 빌려와서 시녀에서 공주가 된다는 컨셉입니다. 네 제가 만들고싶은거 만들었습니다..

여기서 핵심 기능이 하나 있는데, 참가자가 미션 인증 사진을 올리면 **AI가 그 사진이 진짜 해당 미션 사진이 맞는지 판독**하는 것입니다. 운동 인증이라고 해놓고 고양이 사진 올리면 안되니까요. 그리고 하루가 끝나면 AI가 집사 컨셉으로 피드백을 남겨줍니다. "아가씨, 오늘은 6.67점이었답니다" 뭐 이런거요 ㅋㅋ

그래서 OpenAI API를 씁니다. 그리고 이제.. 돈이 나갑니다.

참고로 여기서 "Vision API"라고 부르긴 하는데, 사실 **별도의 Vision API라는 제품을 쓰는게 아닙니다.** 그냥 평소에 쓰는 채팅 엔드포인트에 이미지를 같이 실어보내는거에요.

```
POST /v1/chat/completions
{ "model": "gpt-4.1-mini",
  "messages": [{ "content": [ {"type": "image_url", ... } ] }] }
```

이게 왜 중요하냐면, **별도 제품이 아니니까 별도 요금표도 없기 때문**입니다. 사진도 토큰으로 환산돼서 텍스트랑 같은 지갑에서 나갑니다. 저는 이걸 "장당 얼마"쯤 되는 별개 서비스라고 막연히 생각했었는데, 아니었어요. 그리고 이 오해가 아래 삽질의 출발점이었습니다..

## 비용 산정을 하다가

팀원들한테 운영비를 공유해야해서 계산을 좀 해봤습니다. 대충 이런 조건이에요.

- 참가자 12명
- 30일
- 하루에 인증사진 10장
- → 한 달에 3,600장

모델은 처음에 `gpt-4o-mini`로 통일해서 쓰고 있었습니다. 왜냐면 싸니까요. 토큰 단가를 보면 이렇습니다.

| 모델 | 입력 (1M 토큰당) | 출력 (1M 토큰당) |
| --- | --- | --- |
| gpt-4o-mini | $0.15 | $0.60 |
| gpt-4.1-mini | $0.40 | $1.60 |

딱 봐도 4o-mini가 2.6배 쌉니다. 고민할 것도 없죠. 그래서 대충 월 2,500~4,000원 정도 나오겠거니 하고 있었습니다.

그런데 실제로 토큰 수를 계산해보니까 숫자가 좀.. 이상했습니다.

**월 28,000원이 나왔습니다.**

예상치의 7배입니다. 아니 사진 3,600장 보는데 왜요?

## 이미지는 토큰으로 어떻게 세는가

텍스트야 대충 감이 옵니다. 한글 한 글자에 토큰 몇 개, 이런식으로요. 그런데 이미지는요? 사진 한 장이 몇 토큰인가요?

찾아보니 OpenAI는 이미지를 512×512 짜리 타일로 쪼개서 셉니다. 그리고 여기가 함정이었는데요.

**모델마다 이 타일에 곱하는 가중치가 다릅니다.**

`gpt-4o-mini`의 경우:

```
기본 2,833 토큰 + (타일 하나당 5,667 토큰)
```

숫자가 좀 이상하지 않나요? 저도 처음에 오타인줄 알았습니다. 4o-mini는 이미지 토큰에 **약 33배**의 가중치를 곱합니다. 텍스트 단가가 싼 대신 이미지는 아주 비싸게 치는 구조인 것이죠.

그래서 요즘 폰카로 찍은 1920×1080 사진 한 장을 넣으면:

- 긴 변을 768로 맞춰서 리사이즈 → 1365×768
- 타일 개수 = 3 × 2 = 6개
- 2,833 + (5,667 × 6) = **36,835 토큰**

사진 한 장에 36,835 토큰입니다. 이게 3,600장이면 1억 3천만 토큰이고, $0.15를 곱하면 약 $19.9. 원화로 28,000원.

반면 `gpt-4.1-mini`는 계산 방식 자체가 다릅니다. 32×32 패치 단위로 세고 상한이 1,536패치로 막혀있어요. 그래서 사진이 아무리 커도 대략 2,500 토큰 언저리에서 끝납니다.

| | 장당 토큰 | 월 비용 |
| --- | --- | --- |
| gpt-4o-mini | 약 36,800 | **28,300원** |
| gpt-4.1-mini | 약 2,500 | **5,100원** |

토큰 단가가 2.6배 비싼 모델이, 실제 청구액은 5분의 1이었습니다.

## 그래서 뭘 바꿨냐

두 개 고쳤습니다.

**1. Vision이랑 피드백 모델을 분리했습니다.**

원래 설정 파일에 모델이 하나만 박혀있었어요.

```properties
openai.model=gpt-4o-mini
```

사진 판독이랑 텍스트 피드백을 같은 모델로 돌리고 있었던거죠. 이걸 쪼갰습니다.

```properties
openai.model.vision=gpt-4.1-mini
openai.model.feedback=gpt-4o-mini
```

피드백은 텍스트만 다루니까 4o-mini가 맞고, 사진은 4.1-mini가 맞습니다. 하나로 통일하는게 깔끔해보였는데 그게 아니었습니다..

**2. 사진을 줄여서 보냅니다.**

이건 좀 부끄러운데요. 카메라로 찍은 원본 해상도를 그대로 보내고 있었습니다.

```javascript
canvas.width  = video.videoWidth;   // 축소? 그런거 없음
canvas.height = video.videoHeight;
```

인증 사진이 뭐 예술작품도 아니고.. 긴 변 1,024px면 "이게 운동 사진이 맞나?"를 판단하기엔 차고 넘칩니다. 그래서 줄였어요. 덤으로 저장 용량도 720MB → 150MB가 됐습니다. 업로드도 빨라지고요.

결과적으로 AI 비용은 **월 28,300원 → 5,100원**이 됐습니다. 커피 한 잔 값도 안되게 아꼈지만.. 참가자가 100명이 되면 얘기가 달라지겠죠?

## 여기서 남은 것

사실 이게 대단한 발견은 아닙니다. OpenAI 문서에 다 나와있는 내용이에요. 저는 그냥 문서를 안읽고 "단가 싼거 = 싼거"라고 생각했을 뿐입니다.

그런데 제가 이 글을 남기는 이유는, 이게 **직접 계산해보기 전엔 절대 안보이는 종류의 문제**였기 때문입니다. 코드는 잘 돌아갑니다. 에러도 안납니다. 테스트도 통과합니다. 그냥 한달 뒤에 청구서가 7배로 올 뿐이에요.

지난번에 블로그 글을 어떻게 쓸까 고민하면서 '실험의 글은 유용하다'고 썼었는데요. 이런게 딱 그런 것 같습니다. 어렵진 않은데 귀찮아서 아무도 안해보는 계산이요. 저도 팀원들한테 운영비 공유 안했으면 그냥 넘어갔을 것 같아요.

그리고 하나 더 배운게 있다면, **가격표의 숫자와 실제 청구액은 다른 축에 있다**는 것입니다. 단가는 $/토큰인데 청구액은 $/토큰 × 토큰수라서, 토큰수를 세는 방식이 다르면 단가 비교는 아무 의미가 없어요. 당연한 말인데 저는 몰랐습니다..

혹시 이미지 넣는 AI 기능 만드시는 분이 계시다면, 배포 전에 사진 한 장이 몇 토큰인지 한 번만 계산해보시길 추천드립니다. 5분이면 되고, 저처럼 7배 물어보는 일은 없을거에요.

다음 기록에서는 인증 사진 조작을 어떻게 막았는지 써볼까 합니다. EXIF 파싱해서 촬영날짜 확인하다가 그거 조작 가능하다는걸 깨닫고 갈아엎은 이야기인데.. 이것도 꽤 재밌었거든요.

여기서 마치겠습니다 20000...
