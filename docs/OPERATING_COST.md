## B-3. 적용된 비용 최적화

초기 구현 상태로 두면 Vision 비용만 **월 28,300원**이 나올 구조였습니다.
다음 두 가지를 반영해 **약 24,000원을 절감**했습니다.

**① Vision 모델 분리 — GPT-4o mini → GPT-4.1 mini**

GPT-4o mini는 이미지 토큰에 약 33배 가중치가 붙습니다. 토큰 단가는 더 싸지만
사진 처리에서는 오히려 7배가량 비쌉니다. Vision과 피드백의 모델 설정을 분리했습니다.

```
openai.model.vision   = gpt-4.1-mini
openai.model.feedback = gpt-4o-mini
```

**② 캡처 해상도 축소 — 원본 → 긴 변 1,024px**

카메라 원본 해상도를 그대로 전송하던 것을 1,024px로 축소했습니다.
AI 입력 토큰, 저장 용량, 업로드 속도가 함께 개선됩니다.
