# B. AI API 사용료

## B-0. ⚠️ 먼저 확인이 필요한 부분

현재 코드 상태에서는 **AI Vision 비용이 당초 예상보다 크게 높아질 수 있습니다.**
원인은 두 가지입니다.

**① 사진이 원본 해상도 그대로 전송됨**

`CameraCapture.tsx`가 카메라 해상도를 그대로 캔버스에 담습니다.

```
canvas.width  = video.videoWidth;   // 축소 처리 없음
canvas.height = video.videoHeight;
```

요즘 스마트폰이면 1920×1080 이상이 그대로 올라갑니다.

**② `detail` 옵션이 지정되지 않음**

`OpenAiVisionClient.java`가 이미지를 보낼 때 `detail` 값을 넣지 않아
기본값 `auto`로 동작하고, 큰 이미지는 `high`로 처리됩니다.

```java
Map.of("type", "image_url", "image_url", Map.of("url", dataUri))
// detail 미지정 → auto → 고해상도 분석
```

GPT-4o mini는 이미지 토큰에 약 33배 가중치가 붙기 때문에, 이 조합에서 사진 1장이
**약 36,800 토큰**을 소모합니다.

## B-1. AI Vision (사진 판독)

인증 사진: 12명 × 30일 × 10장 = **3,600장 / 월**

| 시나리오 | 장당 토큰 | 월 입력 토큰 | 단가 | 월 비용 |
| --- | --- | --- | --- | --- |
| ❌ GPT-4o mini + 현재 설정(고해상도) | 약 36,800 | 약 132.6M | $0.15/1M | **$19.9 · 약 28,300원** |
| ✅ GPT-4o mini + `detail: "low"` | 약 2,833 | 약 10.2M | $0.15/1M | **$1.5 · 약 2,200원** |
| ✅ GPT-4.1 mini (기획안) | 약 2,500 | 약 9.0M | $0.40/1M | **$3.6 · 약 5,100원** |

출력 토큰(판정 JSON)은 장당 약 150 토큰으로 월 300~900원 수준입니다.

**권장**: 기획안대로 **GPT-4.1 mini**를 쓰시는 편이 좋습니다. 이미지 토큰 계산 방식이
달라 고해상도로 보내도 비용이 안정적이고, 판독 정확도도 더 높습니다.
GPT-4o mini를 유지하실 경우 `detail: "low"` 지정이 사실상 필수입니다.

> 참고: 현재 `application.properties`의 `openai.model`은 **`gpt-4o-mini` 하나**로
> 설정되어 있어 Vision과 피드백이 같은 모델을 씁니다. 기획안(Vision은 4.1 mini)대로
> 가려면 모델 설정을 둘로 분리해야 합니다.
